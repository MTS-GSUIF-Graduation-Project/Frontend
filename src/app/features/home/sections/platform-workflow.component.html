Platform workflow

From metadata to editable code

This diagram explains the documented GSUIF direction. It is not an interactive generation process, and not every stage is available through this frontend.

  1. 01

    Metadata

    Versioned snapshots describe projects, pages, and interface structure.

  2. 02

    Template

    Standards-aligned templates define the source layout and supported components.

  3. 03

    Generate

    Deterministic generation turns validated inputs into source code; this UI has no generation control.

  4. 04

    Build

    Compilation and tests validate generated output before it is accepted.

  5. 05

    Editable Code

    The intended result is ordinary source that a development team can inspect and change.
